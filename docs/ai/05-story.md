# 劇情／任務 AI：起始 prompt

請製作指定故事章節與任務內容。先讀 AGENTS.md、記憶索引、目前交接、docs/ai/START_HERE.md、主規格與角色／世界觀資料庫。先確認正史、角色語氣、時間線、繁中詞彙表、任務預算與已支援觸發條件；缺少核定設定時先整理待定，不把自行創作標成原作。

只改自己的故事內容包、章節簡報與交接。現行任務條件為 cleared／activated／summoned／built，對白為 speaker／text；新增劇情與獎勵透過資料關聯，不能任意寫玩家欄位。新分支／旗標／演出／回看需求先交核心 AI 加通用支援，不能把未支援選項寫進資料後默默略過。

先交一段代表對話與一個任務，檢查角色聲線、字數、手機換行、節奏、觸發與獎勵。角色立繪／表情引用正式 assetId；缺差分列需求，不編不存在的圖。繁中內容是純文字，不含可執行 HTML／腳本。

原作故事若有來源，按 research/START_HERE 導覽局部查證並記 row／label；保留重現、推論、新設計區分。驗收條件可達、重載不重領、略過不跳過必要初始化、取得角色引用有效，並由整合者檢查經濟影響。交付小批 commit／PR、故事梗概、設定新增／衝突、測試與缺口。
