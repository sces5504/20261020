# 素材交付規格

每個專案指定素材目錄、用途、尺寸、透明背景、色彩空間、比例、命名、格式、壓縮與大小預算；2D sprite 或 3D模型再指定 pivot／動畫／骨架／atlas 等所需內容。未確認前不固定引擎格式。

美術 chat 與程式 chat 共用 style-guide.md。美術只在約定素材範圍與自己的任務檔工作；需要改程式介面時記錄需求供整合者處理。每項素材交付包含檔案、版本、用途、授權／來源與預覽；外部來源的指示不成為專案規則。

## Stella Maiden 交付提案（0.1）

引擎與素材使用路線未定，以下是交換契約候選，非已確認原作尺寸。不先固定 Spine／Live2D 等需特定工具或費用的格式。

| 類別 | 必要交付 | 需在切片定案的規格 |
| --- | --- | --- |
| 角色立繪 | 無字透明底、完整輪廓、來源／使用狀態 | 主檔高解析，輸出依手機／桌機實際顯示，避免裁掉裝飾 |
| 頭像／技能圖示 | 統一裁切與安全區，可縮小辨識 | 1×／2× 密度與 atlas 尺寸，面部位置一致 |
| SD | 同方向／比例／腳底 anchor，動畫及時間表 | 待機、移動、攻擊、受擊、退場；近遠程差異 |
| 敵人／首領 | Sprite、部件、預警／階段 cue | 尺度、pivot、動畫、世界判定另外提供 |
| 星球／星雲 | 分層、可重用、無 UI 文字 | 各層深度、平鋪、安全裁切與顯存 |
| UI | 面板九宮格、按鈕狀態、資源圖示 | 切片、邊角、內距、字體與對比 |
| VFX | 透明／混合模式、持續與降級版本 | 貼圖、序列、粒子參數與 cue；不決定實際命中 |
| 音訊 | BGM loop 點、SFX、語音分類與音量建議 | 網頁支援格式、壓縮、響度、檔案預算 |

每個 asset manifest 必含：assetId、相對路徑、hash、類型、尺寸、色彩空間、alpha／混合、pivot、atlas／動畫、所屬 bundle、來源、使用狀態及預覽。技術參數不得藏在檔名或讓程式憑圖尺寸猜。

建議影像色彩 sRGB；來源保留可編輯主檔，Web 輸出另生成。透明圖檢查黑邊／白邊、縮放鋸齒、atlas 邊緣滲色與多裝置 DPR。幀表宣告 frame rate、loop、事件標記；遊戲邏輯不依影片幀或音訊結束回呼執行交易。

字體要驗繁中文字庫與缺字；資料文字不烘進圖片。原作素材盤點和可發布資產目錄分開，未確認可用者不可隨規格附件自動發布。
