本案採用：戰場保留主要空間、底部編隊清楚區分技能與管理；角色／環境圖片有各自安全區；管理卡用圖片先辨識、名稱與產量接續、主要操作固定在卡片下方；圖示採共同描邊規則，所有關鍵操作保留文字；對話用實際情境背景、深色文字框，手機保持閱讀與下一句可操作。維持太空即時小隊玩法，不套用參考遊戲的戰鬥規則。

後續 AI 需比較實際桌機與手機頁面、讀取同一 style-guide 與 asset-contract，不各自換色票／字體／按鈕語彙。既有星球是可替換的原創程序插畫，普通敵／Boss已採分別生成的AI候選，AI 艦橋／地表／設施／敵艦亦仍為 candidate；要提高完成度時逐項替換共享素材引用，不能把低清占位當已驗收商業素材。
