# 探索版 0.2：試玩回饋實作契約

來源：2026-10-21 使用者直接提出的 16 項回饋。此指示取代舊規格中的在線防衛、失守／修復與避彈訓練；保留原始立繪不改寫，新的明確 Q 圖要求授權另外製作戰鬥衍生圖。

## 玩法與經濟

- 預設在銀河中持續航行，靠近星球掃描發現；可切換既有全域大星圖。點擊與 WASD／方向鍵共用世界移動，管理面板／確認視窗／背景暫停模擬。
- 航路巡邏由 `regions[].patrols` 定義座標、敵群、獎勵、再出現時間。接近才觸發，勝敗都不解放星球；戰後冷卻保存在存檔，不以離線時間補打敵人。
- 星球遭遇由初始 `enemies` 加 `waves` 定義後續敵群，`waveDelay` 控制增援間隔。擊破第一群不視為通關，不靠無敵等待拖長戰鬥。初始隊伍經一次強化、模擬走位與自動技能，三據點約 41／52／70 秒；這是測試種子樣本，不保證所有裝備／操作固定秒數。
- 初始四資源由每種600改為水晶180／氣體170／金屬240／乙太150，倉儲2400；單次離線生產上限1小時。星球基礎產量、首次獎勵與任務獎勵下修，建設仍在1分鐘完成。首星基礎每分鐘8.4／5.4／3.6／2.4；第二顆星球另加3／3／13.2／6，金屬成長可感。
- 舊存檔餘額不強制扣除；新節奏從新版產出／費用生效。設定可「開始新航跡（先備份）」重測新開局；同時建議先手動匯出保存。舊失守領地載入即恢復，不收修復費。防衛倒數／襲擊／訓練沒有 runtime 入口；舊 schema 的對應欄位僅讀檔相容，不再執行。

## 畫面與互動

- 六張人物原 PNG 保持位元組不變。六張新 Q 圖逐張以各自原圖為參考生成，獨立於 `art/characters/battle`，來源／hash／候選狀態見 `art/catalog/battle-assets.json`。未宣稱使用者已核定新Q圖。
- 航行和戰鬥都引用 `characters[].sprite`，不依角色ID分支。戰場依DPR至多2倍繪製，文字獨立高密度，血條在角色圖之上。角色浮動、射擊預警、技能cut-in與倒數回饋保持邏輯／視覺分離。
- 不再呼叫瀏覽器 `confirm`／`alert`／`prompt`。`presentation/dialog.ts` 提供遊戲內確認視窗、取消、鍵盤焦點、Escape；共鳴、撤離、匯入、刪除、恢復及新開局皆用同一元件。
- 主畫面人物可開大立繪、角色敘述與完整技能說明；另設角色庫與編隊面板。戰鬥中保留頭像點擊施放與獨立技能情報，鍵盤1～6仍可施放。
- 技能的實際數值描述由共用 effect／power／duration／cooldown 組成，與編輯器修改同步，不以名稱猜效果。資料中的角色簡介／對白是本案原創，不冒充原作逐字劇情。
- 共鳴完工時把實例ID寫入 `acquisitionQueue`；取得畫面顯示大立繪、星級、姓名、定位與簡介，確認後才清除。批次依序展示，重載不遺失，取消確認不扣費。
- 劇情沿用 `quests[].dialogue`，加入 `intro` 條件與 `storySeen`。以立繪、發言人、對話框、下一句／略過呈現，章節可於航行紀錄回看，之後可直接加資料延伸。
- 領地總覽列出全部已解放／啟動星球、產量、建設管理與導航。手機預設不自動展開星球卡，需點選才開，可關閉；移除防衛通知佔位。Toast短暫顯示後消失。

## 驗收

核心：多波次、巡邏不解放、反覆獎勵保護、取得佇列、資源成長、壞引用與舊存檔相容。瀏覽器：對話換句／略過、WASD與手機點擊、DPR2、大星圖切換、人物／編隊／技能情報、所有確認均為遊戲內、共鳴取得完整流程、領地管理、巡邏自然碰撞與撤離、角色表120列及12建議條目。另保留工坊／ZIP／隔離存檔／多分頁CAS回歸。真機與玩家主觀美術／打擊感驗收保持獨立，不把自動測試通過當成商業品質已審閱。

驗證結果：23項核心測試、TypeScript／內容校驗、build、`test:e2e`／`test:playtest`／`test:exploration`三組Chromium流程全部通過；template10項／stage通過。原六圖hash與美術SQLite重驗通過。測試含桌面及390×844、DPR2觸控模擬，非Android／iOS真機。
