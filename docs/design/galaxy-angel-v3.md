# Galaxy Angel 0.3：航行、編隊與內容展示契約

來源：2026-10-21 使用者八項試玩回饋。產品正式名稱改為 **Galaxy Angel**；此文件補充並優先於 exploration-v2.md 的同名行為。歷史研究仍稱 Stella Maiden，內容 ID、IndexedDB 名稱與舊存檔識別保持相容。防衛、失守、修復、訓練不恢復。

## 可驗收行為

1. 敵艦沿橢圓巡邏，畫出的敵艦位置與觸發位置一致；可見偵測圈，正式內容半徑290，舊版130。面板／對話／背景暫停巡邏時間，離線不補打。勝敗冷卻照舊。
2. 星圖和實際戰鬥都能 WASD／方向鍵連續移動，斜向正規化；放開後停止。修正原先每步3.17單位小於戰鬥5單位停止門檻的問題。攝影機跟隨獨立隊伍錨點，不以隊員跟隨誤差回饋移動指令。
3. 01為面向 +X 的前鋒，後續位置為錯開的後衛，適合將坦克排第一格；敵人仍以實際距離選目標，沒有隱藏職業嘲諷加成。編隊有前移／後移，戰中禁止重排；槽位持續保存。角色死亡保留原槽位，不讓後衛突然換位。
4. 各隊員以不同跟隨時間平滑追上隊伍，單位速度仍影響追趕。導航和戰鬥共用槽位計算。待機有獨立相位的浮動與輕擺，純視覺不改命中判定；面板時停止動畫。導航模式同樣有柔順跟隨。
5. 顯示尺寸由 rules 控制：少女78、普通敵55、Boss112世界單位；編隊間距106。圖片大小不更動碰撞半徑。DPR2與觸控操作沿用0.2。
6. 劇情以任務引用背景，開場／共鳴為艦橋，解放／建設為地表；手機裁切背景，不裁寫人物原圖。星域有獨立宇宙背景引用。
7. 工坊敵人／Boss／星球／建築／研究／星域／劇情都有清單縮圖與詳情圖片；sprite／background 都是可替換素材ID。領地卡、建設、星球情報也顯示同一圖片。
8. 產品頁標題、遊戲、工坊、人物原圖與後續角色表改為新名稱。四資源、六人映射、首勝／共鳴／本機存檔規則維持。

## 內容欄位（以 schema.ts 為執行真值）

| 欄位 | 意義與限制 |
| --- | --- |
| regions[].patrols[].x/y | 路線中心，不是即時敵艦位置 |
| patrolRadius | 水平半徑0–500；垂直半徑為0.62倍；路線必須在星域內。舊包缺省0保持靜止，新正式內容180 |
| patrolSpeed | 相位速度，5–120；角速度=patrolSpeed/max(1,patrolRadius)，正式38；不是橢圓弧長恆速 |
| phase | 起始相位0–6.284弧度；正式三隊錯開相位 |
| detectionRadius | 距即時敵艦位置100–600內觸發，缺省290 |
| buildings/research/regions[].sprite | 列表與展示用素材ID，缺省空字串；缺引用校驗失敗 |
| regions[].background | 星域宇宙背景素材ID，缺省空；非戰鬥邏輯 |
| quests[].background | 整章對話背景素材ID；缺省空，舊包保留漸層後備；新正式章節全部有圖 |
| rules.formationSpacing | 60–180；正式106；純槽位幾何，非固定角色ID |
| rules.allySpriteSize/enemySpriteSize/bossSpriteSize | 各類呈現尺度，缺省78／55／112 |

`domain/navigation.ts` 是巡邏位置與編隊槽位的共用純函式。不要在 Phaser 或編輯器重寫一份偵測公式。未新增任意 Boss AI、路徑編輯器、自由腳本技能或角色語音；新能力交由核心整合者擴充契約。

## 資產與品質界線

六張 standard 原圖及映射不動。新 AI 環境／物件主檔與自行繪製 Canvas 星球主檔保存在 art/world；網頁 WebP 保留尺寸與透明度，清單 art/catalog/world-assets.json 記主檔與輸出hash、來源、candidate。runtime 只複製已校驗輸出，工坊 ZIP 帶入實檔；壓縮／解壓上限不增加。新增美術是待試玩候選，不能自行標為使用者已核定。

UI 線條圖示為本案原創 SVG；卡片、圖片安全區、金色主要動作、青色資訊與紅色威脅共用樣式。參考觀察見 docs/art/ui-reference-20261021.md；不拷貝他作UI素材。商業品質仍待使用者手感／美術審閱及 Android／iOS 真機、效能驗證；自動測試不是商業品質核准。

呈現預算：戰場小型sprite貼圖載入時至多512像素，背景至多1800（低特效1024）；僅呈現快取，原始圖、工坊預覽與內容包原輸出不改。有星空圖時不再重複畫大型程序星雲，星點120／低特效60；敵艦圖載入後不疊畫程序後備。這是負擔改善，未宣稱真機FPS門檻已驗。

前景計時由application/simulation-clock.ts以Phaser rawDelta推進固定1/60步長，避免smoothDelta在慢畫格沿用舊值造成時間流失；單一前景停頓最多補1秒／60步。面板與背景清空累積，visibilitychange後丟棄首畫格的隱藏間隔，不能將離線時間補成戰鬥／巡邏。對應測試包括不同畫格切分的一秒等價，以及暫停／回前景不補打。
