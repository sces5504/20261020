# 星河戰姬 Galaxy Angel 0.5：補給、隊形與星域往返

來源：2026-10-21使用者八項直接試玩回饋。此文件優先於0.4同名舊規則；新數值與跟隨演算法是本案設計，不宣稱已重現Stella Maiden原生公式。原始六立繪不動，防衛／訓練不恢復。

## 可驗收行為

1. 任務的一次性資源獎勵高於早期被動產量，序章提供可用於三人升級／研究的補給；領取仍冪等，已領的舊任務不重發。未領任務用新版金額。星球被動產量不變。
2. 掉頭時後排維持位置等待隊長走到新方向前方，且航跡目標不再要求倒走才接續跟隨；不瞬移／整隊旋轉。掉隊者加速追上，正常行軍保留個別追隨／idle。用實際隊形協助隊長擋彈，沒有新增嘲諷或免傷。
3. 工坊入口需輸入使用者指定的四位碼；錯誤不載入編輯頁。同分頁session解鎖，重新整理可繼續，關閉分頁或按鎖定即需重輸。已保存草稿保留；鎖定前使用遊戲內確認提醒未保存表單。**這是GitHub Pages的前端便利鎖，可被讀原始碼或修改前端狀態繞過，不是伺服器授權或資產保密措施。** 不新增帳號、後端或付費服務。
4. 電腦M在銀河／大星圖之間切換，戰中也可用；按住不連續切換，輸入欄位／管理面板／確認視窗／Ctrl／Alt／Meta組合不觸發。手機保留按鈕。
5. 近距離敵人持續小幅往返側移，遠距追擊仍有效，不停在射程停止點；被玩家接近時只側移，不主動後退至最遠射程。`enemies[].orbitSpeed`可調0–2弧度／秒的角速上限，約7.85秒一個往返週期，普通預設0.45、Boss正式0.25；0保留原停止射擊方式。`strafeSpeed`控制近距側移速限，正式普通敵14、Boss6世界單位／秒；遠距追擊沿用speed，避免敵人因側移而難以被基本攻擊命中。依穩定單位順序決定繞行方向，不用角色ID特例。
6. 滑鼠或數字鍵施放成功時立即刷新該格技能冷卻，移除就緒動畫／光暈；游標停在按鈕上也不能看似仍就緒。完成冷卻才恢復亮框，自動技能沿既有更新機制同步；低動態設定保留靜態提示。
7. 共鳴等待顯示共鳴圖案，不提前洩漏抽選結果；建造等待顯示設施圖片，研究／治療沿用其圖片。任務側欄與工作列表共用圖案；移動至空星域仍可看等待工作。
8. 增加空白第二星域，可從「星域航路」前往並返回；沒有星球、巡邏、敵人或新增獎勵。選目的地→遊戲內確認→抵達該區入口。取消不改存檔；戰中不能躍遷，原領地／工作／資源／收藏保留，重載保留所在星域。正式第二星域日後填內容，不能只加資料卻沒有可達入口。

第一星球各資源產速8.4／5.4／3.6／2.4每分鐘；上述每項任務各資源皆至少相當於10分鐘第一星球產出。這是開局資源推進預設，不是所有滿級領地固定倍率；不把production拉高抵銷任務價值。序章補給＋初始資源可供三位初始角色各強化兩級並開始第一階武裝研究，仍保留建設新星球的長期產能價值。

`regions[].routes`：陣列，缺省空。每項 `{ to: regionId, label: 顯示名稱, requires: planetId[] }`，requires缺省空；引用必須存在，不得指自身／重複目的地。對方status須active且所有前置已解放才能進入。航線是有向的，回程要明確配置。星域入口必須在可航行邊界內。

測試資料：`m1:helios` ↔ `m1:frontier-test`，雙向無前置、無費用，第二星域2800×2000、入口600/1000。`travel`通用命令驗證當前航路／前置／交戰狀態；跨區後重建FleetMotion並置於目的地入口。往返不記上次各區最後座標；區內移動仍不瞬移。新區無星球時正確顯示空域說明、隱藏星球情報，不畫別區的導航箭頭。領地管理可跨區操作；導航到別區領地仍必須有合法航路。

FleetMotion反向判定為新舊方向夾角cos < -0.35，後排個別等待隊長領先至少槽位序號×間距×0.7且目標不要求明顯倒走；之後沿航跡跟上。正常追趕上限約航速1.12倍，依掉隊距離平滑增加到最多2.2倍；每步位移有上限，無座標重排。現有碰撞／擋彈規則維持，移動演算法不保證攔下所有角度的子彈。

核心包0.5.0，requires精確更新；schema1舊存檔不清除。舊包regions缺routes時仍可玩原單一星域，沒有憑空捏造跳轉；要新版測試星域先備份工坊草稿再從新版正式內容建立。全域rules仍以內容包JSON調整，工坊星域routes以JSON欄位編輯。
