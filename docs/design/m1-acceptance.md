## 限制與下一輪優先項

1. 未在 Android Chrome／iOS Safari 實體手機驗證。觸控 viewport 是瀏覽器模擬，不能代替真機。獨立 AI 接力擴充尚未實際演練；本輪資料新增測試不能冒充另一 AI 接手。
2. 雲端 headless Chromium 的 90 幀採樣記於 `.artifacts/m1/performance.json`；此輪 p95 約 136ms、平均 63.6ms；軟體繪圖環境波動，尚未達成可驗收的效能基準，不宣稱全裝置 60fps。依實際手機回報優化繪製、特效與載入。Phaser 主 chunk 約 1.48MB（gzip 約 340KB）；遊戲引擎按路由延遲載入，角色圖按隊伍需求載入。
3. 六角色靜態原圖沒有生成差分／SD／動畫。AI 程序材質與音效已可用；美術一致性、打擊感與聽感仍需使用者實玩審閱，不能稱商業品質已驗收。未包含 BGM 或語音。
4. 這是 Stella Maiden 研究導向的原創 M1 數值／技能／劇情切片。研究有界 Q16 四例已驗，完整 native 暴擊／迴避 RNG、稀有度抽選、融合／重複用途仍保留未知；不以示範配方或技能冒充精確原作。
5. 遭遇重載回進場快照，不存每顆子彈。內容包只能新增定義，覆寫由工坊完整快照或整合者明確修改；沒有任意腳本、通用 migration DSL、公開 mod 市集或雲端存檔。
6. 本機存檔受網址來源／瀏覽器隔離，建議先匯出再清網站資料、換裝置或測大幅內容修改。修復遷移先預覽並保留備份，未來版本 schema 保持拒絕執行。
