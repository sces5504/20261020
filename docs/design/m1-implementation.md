## 最新美術要求

使用者重傳的 27,533,327-byte ZIP 已安全解開，六張標準立繪逐張檢視；原檔 hash 與 manifest 相符。較小 ZIP 有 12 張髮型板，未附原 PDF；來源保留原預期 hash 並標缺件。已查 SQLite 並實際看板。

使用者其後明確修正：「你怎麼亂改我的圖，就原本那樣就好」。已停止本輪 SD 生成，不採用產物；六張 `art/characters/standard/maiden-*/v1.png` 原樣保留。`#/art` 直接展示原檔，沒有生成新人物、裁切／重存或改比例主檔。CSS 僅縮放排版。此指示優先於較舊交接中的差分製作 prompt。

使用者較新明確要求不等待映射，將原本 M1 的六角色套用這六張圖。已依使用者明確指定綁定：05 地球、04 水星、01 金星、03 火星、02 天王星、06 月球。`content/core/art-bindings.json` 與美術庫有明確對應；原圖供立繪、介面頭像視窗與戰鬥全身呈現，不生成 SD，不改原檔比例／內容。

## 技術落地

- TypeScript 5.8.3、Phaser 3.90.0、Vite 6.4.4、Zod 3.24.2、fflate 0.8.3；版本鎖於 package-lock.json。使用者授權開工後採用先前優先方案；無新付費服務。
- `src/domain`：無瀏覽器依賴的戰鬥、移動、彈體掃掠命中、通用技能、四資源、配方／工作、經營結算、編隊／占用／成長與任務命令。
- `src/application/game.ts`：序列化業務命令，戰鬥結果差異提交；管理／使用者／背景暫停原因分開，經營牆鐘獨立。
- `src/platform/storage.ts`：IndexedDB revision CAS、提交前保留上一份備份、存檔檢查、匯出／匯入。失敗保留原檔並提供恢復匯出。
- `src/content/schema.ts`：遊戲／工坊共用結構與語意校驗；`loader.ts` 驗新增內容包依賴／版本／命名空間／循環及重複引用。
- `src/presentation`：Phaser 戰場及 DOM 遊戲面板、工坊、六張原圖庫。介面不直接改錢包或生命。
- 四資源目前具名但未宣稱已證明與原作 native 槽位的順序映射。正式原生配方需要完成映射與未恢復分支。

## 執行與接力

```bash
npm ci --ignore-scripts
npm run dev
```

遊戲 `#/play`，工坊 `#/studio`，原圖 `#/art`，工坊生成的隔離測試 `#/test`。GitHub Pages 子路徑以相對資產路徑支援，正式部署只取 `.artifacts/site`。

內容包作者見 [AI 分工與起始 prompts](../ai/START_HERE.md)。各 AI 只改自己的包與交接，整合者統一維護共用契約及 `content/manifest.json`。生成的 `content/generated/runtime.json` 不提交；開工／建置／測試命令會重建。

驗證結果與目前 commit／工作樹狀態見 [M1 交接](../handoffs/m1-implementation-20261020.md)。

使用者明確選用原圖後，runtime AssetDef 標 approved（僅原圖選用），美術來源記 user-selected-original；整體遊戲品質、動畫、音效與真機仍由各自門檻驗收，不要求對同批原圖重複批准。
