| --- | --- |
| status | 對自己、半徑內友／敵、鎖定敵人套用多個獨立狀態；可含異常／傷害抗性 |

| zone／beam | 固定或跟隨施法者的持續場、牽引、週期傷害；定向／追蹤光束以同一寬度／射程判定與繪製 |

偏折改變方向但維持原陣營；反射切換陣營與歸屬，保留彈體基礎攻擊；抵消直接消除。每個屏障對同一彈體只檢查一次。穿透以掃掠線段先撞最近的敵人，同一彈體不重複命中同一單位；連鎖明示允許再次追擊。巨大化可取消穿透／濺射附加效果，仍承受本體命中。

## 數值、界限與相容

倍率1代表100%；時長秒、角度弧度、距離採遊戲世界單位。Skill.f56=800的原作文字8公尺對應本版800世界單位，不依螢幕大小縮放判定。Skill.levels覆寫2–10級的CD與動作；一般玩家沒有技能強化新流程，預設Lv1，測試場能獨立選技能級別。

保留已驗證的有界Q16傷害helper；新機制在超出原生有界輸入時採同順序的BigInt擴展，明確是本作策略，不模擬未知原生溢位。支援非負有限數值至1e9。原生f90無視迴避、f91抑制暴擊會傳到真實命中／週期判定。

戰鬥步進0 < dt ≤ 0.25；正式及測試場皆用1/60固定步進。單動作最多64枚、16批；配置遭遇會先估算預算（3000彈體／256單位／128持續場），超限內容拒絕通過校驗；單場安全預算3000彈體／256單位，超限明確報錯，不能靜默省略有效敵彈。測試場會保留畫面並暫停回報。

舊七種effect仍可載入舊草稿／ZIP，不自動覆寫作者工作。新program必須有actions；levels／sourceSkill／fidelity皆為可選相容欄位。存檔schema仍1，角色ID、已投入工作與資源ID不改；戰鬥暫態從未寫入玩家存檔，因此無狀態物件遷移。舊草稿由「從新版正式內容建立草稿」保留復原歷史後更新。

ZIP快照為既有16位原圖／Q圖與新增完整技能庫保留位元組；壓縮上限64MiB、解壓總量128MiB、單檔30MiB獨立限制，來源位元組SHA去重。拒絕路徑逃逸、超限展開和缺媒體。沒有重新編碼原六人立繪以騰空間。
