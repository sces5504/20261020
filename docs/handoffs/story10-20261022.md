## 可重現命令

在repo根先 `source scripts/env.sh`。研究SQLite需先依研究入口驗證及重建；安裝沿lockfile，Playwright沿tools既有依賴。

```bash
npm run content:check
npm test
npm run typecheck
npm run build
node --import tsx docs/handoffs/story10-20261022.verify.mts
node --import tsx docs/handoffs/story10-20261022.browser.mts
```

新增包驗收腳本只讀repo資料，輸出 `.artifacts/story10`；verify腳本需啟動唯讀SQLite查詢子程序，browser需本機listen／Chromium執行權限。browser讀verify輸出的pack，必須依順序執行；只寫新browser context的隔離草稿／測試存檔。根manifest不變，runtime生成檔不手編。
