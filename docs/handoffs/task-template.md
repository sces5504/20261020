# 任務交接格式

複製為 `<task-id>.md`；每個任務各用一檔，避免美術與程式 chat 改同一份長紀錄。

- 任務／範圍／branch：
- 狀態與最近更新：
- 開工 HEAD／最後整合 commit：
- 已完成（相關檔案、可觀察結果）：
- 測試（命令、結果、時間、測試時 HEAD、是否有未提交修改）：
- 未完成、已知問題與阻塞：
- 新增要求／規則／偏好：內容、直接使用者來源與日期；推測另標待確認。
- 決策及原因：指向 decisions.md，避免重複整份。
- 美術基準／素材變更／需要檢視的畫面：
- 部署網址與 commit／回復路徑：
- 未提交修改／已推送分支／PR：
- 下一個 AI 的前 1–3 個具體動作：

共享之前提交或推送到約定分支，並在 chat 提供分支／PR及任務檔路徑。接手者先核對目前 HEAD，避免把不同 commit 的測試結果套到現在。
